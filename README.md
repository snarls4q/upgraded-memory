# Simple Calculator

A responsive calculator built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Run it

Open [`index.html`](index.html) in a web browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal input
- Clear and delete controls
- Keyboard support: numbers, `+`, `-`, `*`, `/`, `.`, `Enter` or `=`, `Backspace`, and `Escape`
- Responsive layout and accessible button labels

## Files

- `index.html` — calculator markup
- `styles.css` — layout and styling
- `script.js` — calculator behavior
